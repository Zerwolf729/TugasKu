## 14. Strategi Git yang Disarankan

Buat commit kecil, jelas, dan dapat ditinjau. Contoh urutan: 1.
`chore: initialize Flutter project and repository` 2.
`design: add light theme and shared UI tokens` 3.
`feat: build task list and empty state` 4.
`feat: add task form and validation` 5.
`feat: add task detail and edit flow` 6.
`feat: implement local database CRUD` 7.
`feat: add status filters and task progress` 8.
`test: verify offline persistence and responsive layouts` 9.
`docs: add README and practical report evidence`

Sesuaikan pesan commit dengan perubahan nyata. Commit tidak boleh hanya
dibuat untuk memenuhi jumlah; setiap commit harus bermakna.
