## 15. Definisi Selesai

Aplikasi dianggap siap untuk demo apabila: - Keempat layar utama
tersedia dan saling terhubung. - CRUD dan perubahan status berfungsi. -
Data tersimpan secara lokal dan tetap tersedia tanpa internet. - UI
menggunakan design tokens secara konsisten. - Layout aman terhadap
notch/punch-hole, system bars, keyboard, dan ukuran layar yang
berbeda. - Tidak ada overflow utama atau kontrol yang sulit disentuh. -
Repository memiliki histori Git yang bermakna. - README, screenshot,
refleksi teknis, jawaban pertanyaan demo, dan PDF pengumpulan sudah
disiapkan.

**Prinsip akhir:** desain yang baik bukan hanya terlihat rapi di satu
emulator, tetapi tetap terbaca, aman digunakan, konsisten, dan berfungsi
pada kondisi perangkat serta data yang berbeda.
